# Автоматизация уличного освещения (Home Assistant)

Файл `outdoor_lights.yaml` — пакет Home Assistant, который:

1. **Вечером включает свет** на участке и во дворе, когда датчик освещённости
   показывает меньше порога (по умолчанию 30 lx) дольше 5 минут.
2. **Выключает свет в 00:00.**
3. Если датчик освещённости недоступен — включает свет через 15 минут после заката.
4. После перезапуска Home Assistant вечером сам проверяет, не пора ли включить свет.

Порог освещённости меняется в интерфейсе: сущность
`input_number.outdoor_lights_lux_threshold`.

## Что заменить

| В файле                     | На что                                  |
|-----------------------------|-----------------------------------------|
| `sensor.outdoor_illuminance`| ваш датчик освещённости (lx)            |
| `light.uchastok`            | свет на участке                         |
| `light.dvor`                | свет во дворе                           |

Если светом управляют реле (`switch.*`), замените группу `light` на `switch`
и сервисы `light.turn_on/turn_off` на `switch.turn_on/turn_off`.

## Установка

```yaml
# configuration.yaml
homeassistant:
  packages: !include_dir_named packages
```

Скопируйте `outdoor_lights.yaml` в `<config>/packages/`, затем
**Настройки → Система → Перезагрузка** (или проверьте конфигурацию в
«Инструменты разработчика → YAML → Проверить конфигурацию»).
