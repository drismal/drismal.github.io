# Divergence Ring — живой экран умного дома

Полноэкранная анимация для настенного Android-планшета. В центре живёт тонкое чернильное кольцо.
Когда в доме что-то происходит, в секторе датчика вырастают хребты из частиц и шип.
На кончике шипа появляется шестиугольный маркер, от него идёт выноска с текстом снаружи кольца.
Потом событие оседает.

Стек: Vite + TypeScript + Three.js (WebGL2), без React. Всё офлайн: шрифты и библиотеки лежат локально.

## Сборка

```bash
cd divergence
npm install
npm run build        # результат в dist/
npm run dev          # разработка с горячей перезагрузкой
npm test             # приёмка по разделу 9 (Playwright, 1280×800), нужен собранный dist/
```

Готовая сборка `dist/` уже лежит в репозитории, поэтому собирать необязательно.

## Установка в Home Assistant

1. Скопируйте содержимое `dist/` в `/config/www/divergence/` на сервере Home Assistant.
2. Создайте долгоживущий токен: профиль пользователя → «Безопасность» → «Долгосрочные токены доступа».
3. Откройте `/config/www/divergence/config.json` и пропишите:
   ```json
   "adapter": "homeassistant",
   "homeassistant": { "url": "http://homeassistant.local:8123", "token": "ВАШ_ТОКЕН" }
   ```
4. На планшете откройте `http://<ha>:8123/local/divergence/index.html`.

Токен лежит в `config.json` открытым текстом, а папку `/local/` Home Assistant раздаёт без авторизации.
Поэтому используйте отдельного пользователя только с правами чтения и держите экран в домашней сети.

### Fully Kiosk Browser

## Добавить датчик

Редактируйте `config.json`, пересборка не нужна:

```json
{
  "id": "gate",
  "entity": "binary_sensor.gate",
  "angle": 45,
  "title": "GATE, FRONT YARD",
  "rules": [
    { "when": "state == 'on'", "level": 1, "text": "ENTRY GATE OPEN", "value": "STATUS: OPEN" },
    { "when": "state == 'on' && minutes >= 10", "level": 2, "text": "GATE OPEN FOR OVER 10 MIN" }
  ]
}
```

- `angle` — сторона кольца: 0° = справа, отсчёт по часовой стрелке. Удобно ставить по реальному направлению датчика.
- `level` — 1 мелкое, 2 заметное, 3 тревога (затмение). Срабатывает правило с наибольшим уровнем.
- `value` — 4-я строка. Подстановки: `{value}`, `{unit}`, `{state}`, `{delta:180}` (изменение за 180 минут).
- `staleMinutes` — через сколько минут без данных показать «SENSOR CONNECTION LOST». По умолчанию 15, `0` — отключить.

Язык правил `when`:

| Что | Пример |
|---|---|
| состояние и число | `state == 'on'`, `value > 35` |
| сколько длится текущее состояние | `minutes >= 10`, `seconds > 30` |
| сколько минут нет данных | `stale > 15` |
| диапазоны | `outside(207, 253)`, `between(25, 70)` |
| изменение за N минут | `delta(180) < -3`, `abs(delta(60)) > 5` |
| атрибут Home Assistant | `attr('wind_speed') > 20` |
| логика | `&&`, `\|\|`, `!`, скобки |

Изменения за N минут считаются по истории в памяти экрана. Они начинают работать через N минут после запуска.

MQTT вместо Home Assistant: `"adapter": "mqtt"`, `"mqtt": { "url": "ws://брокер:9001" }`.
У датчиков укажите `"topic"`, а для JSON-сообщений ещё `"valuePath": "voltage"`.

## Ночной режим

`"night": { "source": "ha_sun" }` включает ночь по `sun.sun` из Home Assistant.
`"source": "time", "from": "22:00", "to": "07:00"` — по времени, `"off"` — никогда.
Переход длится 10 секунд.

## Отладка

| Адрес / клавиша | Действие |
|---|---|
| `?demo=1` | симулятор: случайные события всех уровней каждые 15–60 с |
| `?debug=1` или двойной тап | панель параметров, ручной запуск событий, fps, «сохранить параметры в JSON» |
| `?adapter=none` | без источника данных (для тестов) |
| `?night=1` | сразу ночь |
| `?particles=80000`, `?dpr=1` | вручную задать качество (отключает автоподбор) |
| `1` `2` `3` | событие уровня на случайном угле |
| `0` | сбросить всё |
| `N` | день / ночь |
| `E` | затмение |

Сохранённый с панели JSON вставьте в `config.json` в поле `"params"`.

## Отличия от исходного промта

- **Шрифт.** У Barlow Condensed нет кириллицы. Латиница берётся из Barlow Condensed, кириллица — из Roboto Condensed под тем же именем семейства. Текст по умолчанию на английском.
- **Высота хребтов.** Собственный мягкий ореол кольца занимает 1,03–1,10 R, поэтому хребты высотой из таблицы 6.1 (0,04 / 0,10 / 0,18 R) почти тонут в нём. По умолчанию высоты умножаются на `ridgeHeightScale` = 1,6, чтобы картинка совпадала с референсами. Ставьте 1, если нужны точные числа из таблицы.
- **Отступ выносок.** Целевой отступ — 0,25 R от хребтов. Если на экране не хватает места (крупные события у края при R = 0,4 H), выноска сначала уменьшает текст до 0,5. Только потом отступ ослабляется до 0,15 R и 0,06 R. Совсем без места блок может лечь на хребты, но не на само кольцо и не за экран.
- **Время.** Все сдвиги считаются от `performance.now()`. Шум получает два «часа», которые сбрасываются в разные моменты и плавно смешиваются. Так точность float не деградирует при работе 24/7.

## Структура

```
src/main.ts              инициализация, цикл кадра, автоподбор качества
src/ring/RingPass.ts     полноэкранный шейдер кольца (3, 6.2, 6.3)
src/ring/Ridges.ts       частицы хребтов и шипов (4)
src/ring/Needles.ts      мелкие шипы и иглы (3.5, 4.4)
src/ring/shapes.ts       CPU-зеркало формул (кончик шипа, H(θ))
src/callouts/Callouts.ts SVG-выноски, раскладка, анимации (5)
src/events/EventBus.ts   огибающие, уровни (6)
src/data/*.ts            Home Assistant, MQTT, демо, движок правил
shaders/*.glsl           шейдеры
public/config.json       датчики и правила
public/fonts/            шрифты
tests/acceptance.mjs     приёмка по разделу 9
```
